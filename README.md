#Mediator AI
## App Overview
Mediator AI is an AI-powered team collaboration app designed to help students and project teams manage tasks, meetings, and teamwork challenges. It provides AI-based recommendations to improve project planning and collaboration.

## Problem It Solves
During group projects, teams often face problems like:
- Poor communication
- Unclear task responsibilities
- Difficulty tracking progress
- Lack of coordination between members

Mediator AI helps solve these problems by organizing project work and providing AI-powered guidance.

## Features
- Create project groups
- Manage team tasks
- Assign tasks to members
- Schedule meetings
- Track project progress
- AI Mediator recommendations

## AI Feature

### Ask the AI Mediator
The AI Mediator analyzes team progress, workload, tasks, and project activity to provide useful recommendations for improving teamwork and completing projects successfully.

### AI Instructions / System Prompt
"You are an AI project mediator. Analyze team progress, workload, and tasks. Provide helpful recommendations to improve collaboration, planning, and project completion."
